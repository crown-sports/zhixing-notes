# 知行笔记

想法先记下来。待办和想再看的笔记，都从这里找。

> [!tip]- 第一次打开？先花三分钟试一次
> 按 **Ctrl / ⌘ + N** 新建“周末散步”，写一句想法和一条待办：`- [ ] 出门前给相机充电`。
> 再打开左侧的 **00_开始**，在下面找到它。[[使用说明|查看完整步骤]]。

## 还没做完

点结果回到原笔记勾选，完成的任务会从这里消失。

```query
task-todo:/./ -path:"90_模板/" -file:"00_开始"
```

## 值得再看一次

给笔记加 `#待回顾` 就会出现在这里；看完后移除标签。

```query
tag:#待回顾 -path:"90_模板/"
```

## 收集箱

新笔记先放这里。有空时，再移到笔记或项目文件夹。

```query
path:"01_收集箱/"
```

> [!info]- 日记、模板和每周回顾
> - **记今天**：Ctrl / ⌘ + Shift + D，自动套用每日模板。
> - **用模板**：新建笔记、取好名字后，Ctrl / ⌘ + Shift + T。
> - **每周整理**：[[40_回顾/每周回顾示例|看看一份十分钟回顾]]。
> - **学完自测**：[[20_笔记/回顾卡片/先回忆再看答案|打开一张回顾卡]]。
