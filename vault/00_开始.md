# 知行笔记

记下来 · 想明白 · 用得上

> [!tip] 先记一条，分类可以晚一点
> 按 **Ctrl / ⌘ + N** 新建笔记，它会进入收集箱。写下一句话，给它取个能找回来的名字。

## 今天从哪里开始

| 想做的事 | 入口 |
| --- | --- |
| 记录今天 | **Ctrl / ⌘ + Shift + D**，自动套用每日模板 |
| 写一篇笔记 | 新建后按 **Ctrl / ⌘ + Shift + T** 选择模板 |
| 整理零散想法 | [[01_收集箱/一条灵感的去处\|看看一条灵感怎样变成笔记]] |
| 回顾本周 | [[40_回顾/每周回顾示例\|十分钟回顾示例]] |
| 学完后自测 | [[20_笔记/回顾卡片/先回忆再看答案\|打开一张回顾卡]] |

> [!info]- 按自己的习惯调整
> 日记放在 `10_日记`，长期笔记放在 `20_笔记`，有明确完成标准的事放在 `30_项目`。每周只处理一次收集箱也可以。
> 目录名可以改；改动日记、模板或回顾卡片目录时，同时更新对应设置。
