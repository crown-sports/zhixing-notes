# 三分钟上手

先记一条，再看看它怎样出现在 [[00_开始|首页]]。下面的快捷键在 Windows / Linux 用 **Ctrl**，Mac 用 **⌘**。

## 1. 写一条笔记

按 **Ctrl / ⌘ + N**（或点左侧文件列表的“新建笔记”），命名为 **周末散步**。在正文粘贴：

```markdown
想走一条没去过的路线，拍几张照片。
- [ ] 出门前给相机充电

#待回顾
```

新笔记会自动放进 `01_收集箱`，不用先决定分类。

## 2. 回到首页找到它

打开左侧的 **00_开始**。也可以按 **Ctrl / ⌘ + O**，输入 `00_开始`，按回车。

- **还没做完**：找到“出门前给相机充电”。点结果回到原笔记，勾选方框，再回首页，任务就从这里消失了。
- **值得再看一次**：找到“周末散步”。以后看完了，删掉笔记中的 `#待回顾` 即可。
- **收集箱**：找到刚写的笔记。有空时再移动到 `20_笔记`，或留在这里继续写。

首页只汇总内容。勾选和修改要回到原笔记完成。

## 3. 明天继续记

| 想做什么 | 怎么打开 |
| --- | --- |
| 写今天的日记 | **Ctrl / ⌘ + Shift + D**，或点左侧“打开/创建今天的日记” |
| 记读书、想法或项目 | 先新建、命名，再按 **Ctrl / ⌘ + Shift + T** 插入相应模板 |
| 每周整理一下 | 新建“本周回顾”，插入“每周回顾”模板；参考 [[40_回顾/每周回顾示例\|示例]] |

不必填完模板的每一项。一句话、一个例子，也是一篇笔记。

## 常见问题

**第一次打开，要信任这个库吗？** 先选安全模式也能完成上述操作。两个可选插件默认关闭，等需要时再按 [[插件说明]] 启用。

**没有看到首页汇总？** 在设置 → 核心插件中确认“搜索”已开启。任务写成 `- [ ] 内容`，中间用半角空格；`#待回顾` 前后留空格或换行。模板里的待办不会进入首页列表。

**可以删掉示例吗？** 可以。收集箱、笔记、项目和回顾中的演示内容都是虚构的。想保留日记和模板功能，请保留 `90_模板`；删除普通示例后也可以保留空文件夹。

**已经有自己的库？** 先单独打开试用，再复制需要的模板。不要覆盖原库的 `.obsidian`。模板里的日期要通过“插入模板”替换，直接复制文件不会替换。

**手机能用吗？** 基础功能使用 Obsidian 核心插件，手机端尚未实测；请按 Obsidian 支持的方式导入或同步库。两个可选插件仅限桌面。本项目不提供同步服务。

> [!info]- 各个文件夹放什么
> - `01_收集箱`：还没整理的想法。
> - `10_日记`：当天的记录。
> - `20_笔记`：以后还会用的内容和回顾卡片。
> - `30_项目`：有完成标准、需要几步做完的事。
> - `40_回顾`：每周整理与取舍。
> - `90_模板`：可修改的六种模板。
> - `99_附件`：粘贴或导入的图片等附件。
