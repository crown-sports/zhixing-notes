# 三分钟上手

这是一份全新的示例库。内容均为原创演示，可以删除后开始自己的记录。

1. 打开 [[00_开始|首页]]，按 **Ctrl / ⌘ + N** 写第一条笔记。新笔记和粘贴的附件已有默认位置。
2. 按 **Ctrl / ⌘ + Shift + D** 打开今日日记；按 **Ctrl / ⌘ + Shift + T** 为已命名的普通笔记插入模板。也可以在命令面板搜索“日记”或“模板”。
3. 每周新建一篇回顾，插入“每周回顾”模板。把收集箱里值得留的内容移到笔记，给正在做的项目写下一步。

## 目录只回答一个问题：以后从哪里找它？

| 位置 | 放什么 |
| --- | --- |
| `01_收集箱` | 暂时没整理的片段与想法 |
| `10_日记` | 当天发生的事与下一步 |
| `20_笔记` | 想明白了、以后还会用的内容；回顾卡片也在这里 |
| `30_项目` | 有明确完成标准和下一步的事情 |
| `40_回顾` | 每周取舍与改进 |
| `90_模板` | 可直接修改的六种模板 |
| `99_附件` | 粘贴或导入的图片等附件 |

首页通过 Obsidian 自带搜索汇总收集箱、未完成任务和 `#待回顾`，无需 Dataview 或 Tasks。
未完成任务是普通 `- [ ]`。点开搜索结果，到原笔记勾选；搜索块本身不是任务编辑器。

## 写得少一点，也能用

一篇普通笔记先写**一个观点、一个例子、一个来源**。遇到值得记住的内容，再写一个可自测的问题。
不必给每篇文章制卡，也不必把每个空格填满。一个问题已经想清楚，就可以去做下一件事。

## 插件和手机

基础笔记、模板和搜索由核心插件提供，可在手机上使用；手机端请通过 Obsidian 支持的库打开或同步方式导入。
两个可选插件初版仅支持桌面，见 [[插件说明]]。本项目不提供账号或同步服务。

## 已有库如何使用

先在这个示例库试用，再按需复制 `90_模板` 和个别笔记到已有库。
模板中的日期会在“插入模板”时替换；直接复制文件不会替换日期。
不要把示例库的整个 `.obsidian` 覆盖到已有库。安装插件只复制对应插件文件夹，再在设置中启用。

## 不想继续使用了

所有内容仍是本地 Markdown 和附件，停用插件不影响打开、搜索和编辑。
示例库没有自动上传、AI 请求或需要填写的 API Key。若自行安装第三方插件，请按需查看其说明。

核心功能参考：[Templates](https://obsidian.md/help/plugins/templates)、[Daily notes](https://obsidian.md/help/plugins/daily-notes)、[Search](https://obsidian.md/help/plugins/search)。
