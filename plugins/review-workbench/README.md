# 知行工作台

**记下一条想法，给它找个去处，周末再回头看。**

- **快速记录**：只写正文也能保存，自动取标题，进入收集箱。
- **逐条整理**：看正文预览，保留为笔记、变成项目或归档；最近一次移动可撤销。
- **本周回顾**：把收集箱、待回顾与本周修改的笔记链接存成一篇 Markdown。同周再次点击只打开，不覆盖。
- **回顾卡片**：写问题和答案、遮住答案自测，补充自己的理解。

## 安装与第一次使用

1. 下载 [Releases](https://github.com/crown-sports/zhixing-notes/releases/latest) 的 `review-workbench.zip`，把其中的 `review-workbench` 文件夹放进库的 `.obsidian/plugins/`，缺少 `plugins` 目录时自行创建。完整示例包已包含它。
2. 重启 Obsidian，在“设置 → 第三方插件 / 社区插件”启用 **知行工作台**。
3. 点左侧房子图标，或按 Ctrl / ⌘ + P 搜索 **打开笔记工作台**。先点“快速记录”。

看不到 `.obsidian`？Mac 在 Finder 按 ⌘ + Shift + .；Windows 在资源管理器开启“显示隐藏的项目”。

**更新已有安装**：先停用插件，只替换 `main.js`、`manifest.json`、`styles.css`，保留 `data.json`，再启用。插件 ID 沿用 `review-workbench`，从 0.1.x 更新无需迁移卡片。仅支持桌面。

## 已有笔记库

在插件设置中选择自己的收集箱、笔记、项目、归档、每周回顾目录。保存设置不会移动文件；首次写入时才创建缺失目录。收集箱不能与目标目录重叠。

“变成项目”只移动原文件，内容保持原样。移动通过 Obsidian 完成，链接更新遵循原库设置；同名目标不覆盖。撤销仅针对本次会话最后一次移动，原路径被占用或文件已被外部移动时会停止。

## 本周回顾

从本地时间的周一开始，以周一起始日期命名，例如 `40_回顾/2026-10-19.md`。内容是生成时的链接快照，每组最多 50 篇并标出省略数量。“本周修改”统计收集箱、长期笔记和项目目录；导入或同步也可能改变文件修改时间。已有同周文件只打开，不重复生成。

## 卡片自测

点击工作台里的“回顾卡片”，打开原有卡片功能。默认目录 `20_笔记/回顾卡片`，可以在设置中修改。

新建表单每次一张卡；问题与答案不要放独立标题或分隔线。补充“回顾分析”时会检查并发编辑；存在自定义内容时提示直接编辑原文。

自测输入和这一轮进度不保存，不调整复习日期。需要间隔排期时，可自行安装 [Spaced Repetition](https://github.com/st3v3nmw/obsidian-spaced-repetition)，使用它的原生评分。

## 开发

Node 20+，无需安装依赖。运行 `node build.js` 构建，`node --test *.test.js` 验证。`main.js` 由 `main.src.js`、`data.js`、`desk.js`、`workflow.js` 生成。MIT 许可。
