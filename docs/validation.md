# 验证范围

初版以独立示例库和可选插件发布。自动化测试使用合成 Markdown、内存库和模拟接口，不读取作者的真实笔记。

| 范围 | 检查方式 |
| --- | --- |
| 首页与模板 | 内部链接、JSON、日记与模板路径、默认关闭社区插件 |
| 日常工作台 | 空白记录、Markdown 缩进、同名与并发写入、移动与撤销冲突、目录隔离 |
| 周回顾与恢复 | 本地周起止、跨年与夏令时、模板排除、已有内容保留、恢复标签页复用 |
| 回顾卡片 | 解析、分类、自测数据、新建同名不覆盖、目录限制 |
| 分析写回 | LF / CRLF、编辑冲突、保留无关内容、特殊替换字符 |
| PDF 书签 | 真实位置参数、目录目标、去重、移动文件、异步保存和失败回退 |
| 发布包 | 限定配置输入、拒绝工作区记录与路径穿越、稳定 ZIP 元数据 |

自动化结果以 [GitHub Actions](https://github.com/crown-sports/zhixing-notes/actions) 为准。

## 0.2.0 日常流程复测

2026-10-23，macOS / Obsidian 1.14.4，使用发布包解压的独立测试库：

- 启用知行工作台，房子图标打开首页；重载应用后正常恢复。

## 兼容范围

- 基础库使用 Obsidian 核心 Daily Notes、Templates、Search，适用于支持这些功能的桌面和移动端版本。手机端操作尚未实测。
- 两个自研插件初版标记为仅桌面端，不声称移动端兼容。
- Windows / Linux 应用界面、窄窗口、PDF++ 选区与批注集成尚未实际操作验收；三平台 CI 仅验证构建、测试与打包。
- PDF 书签依赖原生书签、PDF.js 和可选 PDF++ 的内部接口。版本变化可能影响选区、目录或保存；没有选区接口时明确退回当前页。
- 书签失败回退会尽力保留其他编辑，但原生接口不提供磁盘事务保证。具体行为见 [插件说明](../plugins/pdf-location-bookmarks/README.md)。
- 回顾工作台的完整性检查只能发现缺失或占位内容，不能判断答案知识是否正确；自测不等于完成 SR 调度。

## 后续版本的复测清单

在解压得到的独立示例库执行，不要用真实资料试验：

1. 打开首页，检查浅色、深色、窄窗口、内部链接与搜索结果。
2. 新建日记，插入普通模板，勾选任务并核对首页结果。
3. 启用回顾工作台：新建卡片、取消、同名再建、隐藏/显示答案、保存分析。
4. 打开自备测试 PDF：取消收藏后数据不变；保存页码与目录书签后能返回相同位置。
5. 停用两个插件，确认 Markdown 和原生书签仍可使用。
